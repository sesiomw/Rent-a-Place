# Rent-a-Place

O sistema Rent a Place é um software destinado ao auxílio no aluguel de imóveis: casas, apartamentos e espaços comerciais, diferenciando-se por reunir em uma única plataforma as modalidades de aluguel por diária, semanal, mensal e tradicional. O sistema deve ser capaz de realizar o cadastro de usuários e imóveis, processar transações entre o usuário consumidor e o usuário ofertante e aplicar um percentual como margem de lucro sobre essas transações.
